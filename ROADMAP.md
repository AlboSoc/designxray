# Roadmap

## Near term

- Add more worked examples across products, interiors, mechanisms, signage, and public infrastructure.
- Refine the distinction between observation, inference, and speculation.
- Add compact, standard, and deep analysis modes.
- Add guidance for analysing multiple interacting objects rather than isolated artefacts.
- Develop a repeatable method for choosing which features deserve attention.

## Later

- Add image-annotation support.
- Add a machine-readable output schema.
- Develop evaluation examples showing weak versus strong analyses.
- Explore a companion “design synthesis” mode that turns X-ray findings into redesign proposals.
- Package the skill for specific agent platforms as their formats stabilise.
