# Contributing

Contributions should improve either the method, its portability, or the quality of its examples.

## Good contributions

- A worked example with explicit observation/inference/speculation boundaries.
- A clearer formulation of one of the four Ps.
- A useful failure mode or anti-pattern.
- A compact prompt variant for a particular platform.
- A test image and analysis pair, provided the image can legally be redistributed.

## Example quality

A worked example should:

1. Identify visible evidence.
2. Avoid pretending to know undocumented designer intent.
3. Explain plausible causal pressures.
4. Include meaningful failure modes rather than generic criticism.
5. Produce possibilities grounded in the preceding analysis.
6. End with cross-cutting deductions.

Keep the reusable method in `skill/`; keep repository-development notes outside it.
